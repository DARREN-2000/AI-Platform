# 07 — Go

## Baseline
- MUST run `gofmt`/`goimports` and `go vet`; CI MUST run `golangci-lint`.
- MUST keep packages cohesive; MUST NOT create `util`/`common` dumping grounds.
- MUST use Go modules with pinned versions.

## Errors
- MUST return errors as values; MUST wrap with context using `fmt.Errorf("...: %w", err)`.
- MUST NOT use `panic` for ordinary error handling; reserve for unrecoverable startup failures.
- MUST check every returned error; MUST NOT discard with `_` unless justified.

## Concurrency
- MUST pass `context.Context` as the first argument to I/O and long-running functions.
- MUST avoid goroutine leaks: every goroutine has a clear exit and is bounded.
- MUST protect shared state with sync primitives or channels; MUST run tests with `-race`.

## Design
- MUST accept interfaces, return structs.
- MUST define interfaces in the consumer package, kept small.
- SHOULD use composition over embedding for behavior reuse.
- MUST defer-close all resources and check close errors where meaningful.
