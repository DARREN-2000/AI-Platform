# Welcome to Enterprise AI Platform

The Enterprise AI Platform is an open-source, production-ready system for orchestrating, governing, and scaling AI workloads. It consists of five loosely coupled services that work together to provide a seamless generative AI experience backed by your enterprise data.

## Features

- **IntentGraph:** Advanced agent orchestration and dependency graph execution.
- **EnterpriseIQ:** Zero-trust, RBAC-filtered hybrid retrieval (RAG).
- **Inference Control Plane:** A high-throughput LLM gateway providing an OpenAI-compatible API.
- **GuardrailX:** Sub-millisecond policy evaluation and prompt injection detection.
- **AI Hypervisor Platform:** GPU-aware compute virtualization for local models.
