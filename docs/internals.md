# Internals

This section covers the internal workings of the specific repositories.

- **IntentGraph**: Built with Python/Poetry, manages DAG execution.
- **Inference Control Plane**: FastAPI application for LLM routing.
- **GuardrailX**: FastAPI/React governance tool.
- **EnterpriseIQ**: Python-based retrieval pipeline.
- **AI Hypervisor Platform**: Go-based control plane.
