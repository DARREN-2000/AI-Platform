# Security Policy

## Supported Versions

Currently, we support the `main` branch for security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them to the maintainers privately via email (if provided) or through GitHub's security advisory feature under the "Security" tab of this repository.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress.
